# Аудит backend BudgetAnalytics (исходное состояние)

Аудит проведён по коммиту `de0c81f` (first commit + удаление части
.idea/pycache) перед рефакторингом. Перечислены только проблемы,
подтверждённые кодом или запуском.

## A. Текущая архитектура (до изменений)

```
app/
  main.py            FastAPI + lifespan (create_all), CORS "*"
  core/              config (7 обязательных env без значений), database (Base №1),
                     security (python-jose + passlib), logging (не используется)
  models/            base.py (Base №2), User, Transaction, Category, Bank, Budget, Deposit
  schemas/           Pydantic v2 схемы
  api/               роутеры: auth, upload, transaction, budget, investment, dashboard, analytics
                     — SQL, бизнес-логика и HTTP в одном месте
  services/
    analytics/       income, spending, saving, forecasting — отдельный запрос на каждую метрику
    parser/          kaspi.py, halyk.py, freedom.py — три копии одного CSV-парсера
    ai/advisor.py    if/else-правила + доступ к данным
    dashboard.py     не используется API (мёртвый код)
  repo/              пустой пакет
  tasks/             пустые scheduler.py, monthly_report.py
```

Слоёв repository/domain нет; API-хендлеры сами пишут SQL и делают commit.

## B. Найденные проблемы

### Критичные (приложение не работает / данные повреждаются)

| # | Проблема | Где | Последствие |
|---|----------|-----|-------------|
| 1 | `Base.metadata.create_all(bind=engine)` с `AsyncEngine` | `main.py` | приложение падает на старте |
| 2 | Два `DeclarativeBase`: модели наследуют `models/base.py`, `main.py` берёт `core/database.py` | | даже с исправленным вызовом таблицы не создаются |
| 3 | Нет Alembic, схема управляется `create_all` | | нет миграций и отката |
| 4 | `passlib 1.7` + актуальный `bcrypt>=4.1` (разрешается `pip`) | `core/security.py` | **регистрация и логин отвечают 500** (проверено запуском) |
| 5 | Повторная загрузка выписки удваивает операции | `api/upload.py` | неверная аналитика |
| 6 | Ошибка в одной строке выписки (например, сумма `abc`) → необработанный `InvalidOperation` → 500, весь файл теряется | парсеры | нет partial import |

### Изоляция пользователей и безопасность

| # | Проблема | Последствие |

### Что мешало бы AI Coach

* нет детерминированных калькуляторов — модель пришлось бы «считать» самой;
* нет домена долгов, профиля, базы ставок с источниками;
* нет безопасного tool API с серверным контекстом пользователя;
* нет слоя минимизации/редакции ПДн.

Пункты 1–19 и 21–31 исправлены; п. 20 (семантика «баланса») оставлен
как есть для совместимости и явно задокументирован в схеме ответа.
См. `docs/architecture.md` и историю коммитов; тесты на исправления —
в `backend/tests`.
