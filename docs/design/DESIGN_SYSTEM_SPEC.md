# Design System Spec

> Визуальная база — утверждённые дашборды в Figma `spaehjXGVBqqhoqZh22o9C` (узлы `1:17` Light и `1:197` Dark) и токены, уже созданные в файле. Этот документ — контракт для макетов и будущего frontend; frontend ещё не реализован.

## 1. Визуальный язык: Corporate Fintech

- **Иерархия:** ключевой показатель (крупная цифра) → контекст (изменение, период) → детализация (таблица или график).
- **Поверхности:** фон `background` → карточки `surface` с рамкой 1 px `border`, без теней. Тени только у всплывающих слоёв (modal, drawer, dropdown, toast).
- **Акцент:** `brand/primary` — только для главного действия, активной навигации, фокуса и основной серии графика. Не больше одной primary-кнопки в зоне видимости.
- **Скругления:** карточки 12, поля и кнопки 8, бейджи 6, pill-элементы full. Карточки внутри карточек запрещены.
- **Плотность сбалансированная:** строка таблицы 48 px (desktop), шаг сетки 4 px.
- **Без декора,** закрывающего данные: никаких фоновых градиентов, иллюстраций за графиками, glassmorphism.
- **Цвет — не единственный носитель смысла:** положительное/отрицательное значение всегда со знаком `+`/`−`; статус — с текстом или иконкой.

**Миграция при апгрейде тарифа** (не выполнять без отдельного решения):
1. Добавить режим `Dark` в `1:2`.
2. Перенести значения из `11:42` по совпадающим именам.
3. Перепривязать dark-экраны к переменным `1:2` с явным режимом `Dark`.
4. Удалить `11:42` после проверки, что ни один слой на неё не ссылается.

ID переменных Light сохраняются, поэтому утверждённые экраны не ломаются.

### 2.3 Предлагаемые дополнительные токены (на утверждение, аддитивно)

Расчёт контраста показал, что часть семантических цветов **не проходит AA (4.5:1) для мелкого текста в светлой теме** (§8). Чтобы не менять утверждённые значения заливок, предлагается добавить текстовые токены:

| Новый токен | Light | Dark | Контраст Light (на surface / на subtle) |
|---|---|---|---|
| `text/positive` | #11744F | #3CCB91 | 5.78 / 5.14 |
| `text/negative` | #C23D3D | #F07878 | 5.21 / 4.60 |
| `text/warning` | #8F5E14 | #E8B45B | 5.56 / 5.09 |
| `text/info` | #3E69B5 | #79A7F2 | 5.39 / 4.75 |

Миграции не требуется: существующие переменные не меняются, новые используются для текстов сумм и бейджей.

### 2.4 Цвета графиков: порядок и смысл
Порядок серий фиксирован во всех графиках: green → blue → amber → violet → slate.
- **«Доходы vs расходы»:** доход — `chart/green`, расходы — `chart/blue`. Красный не используется для расходов как серии: красный означает только **превышение** или отрицательное значение.
- **Категории:** по убыванию суммы; после 5-й категории — «Прочее» (`chart/slate`).
- **Цвета пользовательских категорий:** `color` из API используется в иконке категории и в легенде разбивки, а не в бизнес-сериях. Если цвет категории контрастирует с фоном меньше 3:1, к маркеру добавляется рамка `border/strong`.

## 4. Отступы, сетка, скругления, тени

- **Шаг:** 4 px. Токены `space/1…12` = 4, 8, 12, 16, 20, 24, 32, 40, 48.
- **Скругления:** `radius/sm` 6, `md` 8, `lg` 12, `xl` 16, `full` 999.
- **Тени (effect styles):**
  - `Elevation/Raised` — карточка при hover или drag;
  - `Elevation/Overlay` — modal, drawer, dropdown, toast;
  - `Focus/Ring` — фокус, 3 px brand @ 28 %.
- **Сетки:**
  | Брейкпоинт | Колонки | Gutter | Поля | Сайдбар |
  |---|---|---|---|---|
  | Desktop 1440 | 12 | 24 | 32 | 248 (развёрнут) |
  | Tablet 768 | 8 | 16 | 24 | 72 (иконки) |
  | Mobile 390 | 4 | 12 | 16 | нет; нижняя навигация + меню |

  Подробнее — [RESPONSIVE_SPEC.md](RESPONSIVE_SPEC.md).

## 5. Иконки
- Стиль контурный, 1.5 px, сетка 24, рабочие размеры 16 / 20 / 24. Одна библиотека; рекомендуется Lucide (лицензия ISC). Выбор библиотеки — решение frontend, нужна проверка версии.
- Иконки категорий — строковые slug из API (`shopping-cart`, `utensils`, `car`, `home`, `wifi`, `heart`, `shirt`, `book`, `film`, `gift`, `credit-card`, `dots`, `briefcase`, `plus`, `repeat`, `wallet`). Большинство имён совпадает с Lucide. Расхождения обрабатываются явной таблицей маппинга на frontend 🟦: `dots` → `ellipsis`; `home` в новых версиях Lucide может называться `house` — **проверить по установленной версии**. Неизвестный slug → `wallet`.
- Иконка в Figma — компонент с INSTANCE_SWAP, а не вариант на каждую иконку.

## 6. Форматирование чисел, дат и валют

Локаль: **ru-KZ** (`Intl.NumberFormat('ru-KZ')`, `Intl.DateTimeFormat('ru-KZ')`).

> ⚠ Нужно проверить фактический вывод `Intl` для `ru-KZ` в целевых браузерах (Chrome, Safari, Firefox) до утверждения: разделитель групп — неразрывный пробел U+00A0 или узкий U+202F, положение символа ₸.

| Значение | Вход API | Отображение | Правило |
|---|---|---|---|
| Сумма KZT | `"1250000.50"` + `KZT` | `1 250 000,50 ₸` | Пробел групп, запятая, символ после числа через неразрывный пробел |
| Целые тенге в метриках | `"1250000.00"` | `1 250 000 ₸` | Нулевые копейки скрываются **только** в крупных метриках; в таблицах и формах всегда 2 знака |
| Другие валюты | `"1500.00"` + `USD` | `1 500,00 $` | Символ из справочника валют; неизвестный код → `1 500,00 USD` |
| Знак | тип транзакции | `+12 500,00 ₸` / `−12 500,00 ₸` | Минус — типографский `−` (U+2212); цвет `text/positive` / `text/primary` (расход не красный) |
| Отрицательный баланс | `"-1500.00"` | `−1 500,00 ₸` | Цвет `text/negative` |
| Проценты | `"80.00"` | `80 %` (метрики) / `80,00 %` (таблицы) | Неразрывный пробел перед `%` |
| Изменение | `"+25.00"` | `▲ 25 %` / `▼ 66,7 %` | Направление и цвет — по смыслу метрики: рост расходов — плохо |
| Процентные пункты | `savings_rate_change_pp` | `+3,4 п. п.` | Отдельно от процентов |
| `null` | — | `—` + tooltip с причиной | Никогда не `0` |
| Дата | `2026-11-18` | `18.11.2026`; в списках — `18 нояб.` | Текущий год в списках не повторяется |
| Дата-время | UTC ISO | `18.11.2026, 22:31` в `tz` | 24-часовой формат |
| Месяц | `2026-11` | `ноябрь 2026` | Именительный падеж в заголовках |
| Период | `date_from`/`date_to` | `1–30 нояб. 2026` | Обе границы включительно |

**Ввод сумм 🟦:** принимать `,` и `.` как десятичный разделитель, пробелы игнорировать, не более 2 знаков после запятой; отправлять в API строку с точкой (`"1250000.50"`).

**Отображение не меняет данные:** округление и усечение для показа — только визуальные, расчёты не повторяются.

### 7.1 Графики — обязательные правила
- **Ось Y:** сокращённые суммы (`1,2 млн ₸`, `850 тыс. ₸`), 4–5 делений, линии сетки `chart/grid`.
- **Ось X:** месяцы — `янв`, `фев`; дни — `18.11`.
- **Легенда:** над графиком слева; маркер, имя серии и итог за период.
- **Tooltip:** точная сумма с копейками, период и все серии точки.
- **Пустые месяцы:** нулевой столбец с подписью, не пропуск (`monthly` возвращает 12 месяцев).
- **Donut:** в центре — итог; в легенде сумма и доля (`share_percent` из API); `null` доля → «—».
- **Доступность:** у каждого графика есть табличное представление («Показать таблицей») 🟦.
