# Responsive Spec

> Три эталонные ширины: **Desktop 1440**, **Tablet 768**, **Mobile 390**. Промежуточные ширины ведут себя как ближайший нижний брейкпоинт: ≥ 1200 → desktop, 768–1199 → tablet, < 768 → mobile. Мобильная версия — не уменьшенный desktop: меняется навигация, представление таблиц и форм.
> Горизонтальный скролл страницы запрещён на всех ширинах. Допускается только внутри явно обозначенного контейнера (таблица на tablet) с тенью-подсказкой у края.

## 2. Поведение экранов

### Обзор (D-1)
| | Desktop | Tablet | Mobile |
|---|---|---|---|
| Метрики (баланс, доход, расход, норма сбережений) | 4 в ряд | 2×2 | Вертикальный список; баланс крупно, 3 остальные — компактные строки |
| Денежный поток | 8/12 ширины, 12 месяцев | Вся ширина, 12 месяцев | Последние 6 месяцев; переключатель «6 мес / год» открывает полный год в портретной таблице |
| Структура расходов | 4/12, donut + легенда | Вся ширина, donut слева, легенда справа | Donut 160 px, легенда списком ниже |
| Бюджеты | Список 3–5 с прогрессом | То же | Карусель запрещена; список из 3 + «Все бюджеты» |
| Последние операции | Таблица 5 строк | Таблица без колонки «Счёт» | Карточки 5 шт. |

### Транзакции (T-1, T-2, T-3)
| | Desktop | Tablet | Mobile |
|---|---|---|---|
| Фильтры | Панель над таблицей: период, тип, категория, счёт, поиск + «Ещё фильтры» (банк, валюта, сумма); активные — чипами | Период + поиск + кнопка «Фильтры (N)» → drawer | Поиск + кнопка «Фильтры (N)» → нижний лист; чипы — горизонтальным рядом с переносом |
| Список | Таблица: Дата · Описание · Категория · Счёт · Банк · Сумма | Таблица: Дата · Описание+категория · Сумма | Карточки по дням (заголовок дня); строка: иконка, описание, категория·счёт, сумма справа |
| Пагинация | Номера страниц + размер страницы | Назад/вперёд + «N из M» | «Показать ещё» (следующий `offset`) |
| Детали | Drawer 480 | Drawer 420 | Отдельный экран |
| Форма | Modal M, 2 колонки для «Сумма | Дата» | Modal, 1 колонка | Полноэкранный лист; тип — segmented control сверху; сумма — крупное поле с цифровой клавиатурой (`inputmode="decimal"`) |

### Импорт (I-1)
Desktop и Tablet — пошаговый мастер в modal L или на отдельной странице. Mobile — пошаговые экраны; таблица предпросмотра превращается в карточки строк со статус-бейджем; исключение строки — переключатель на карточке.

### Счета, Категории, Депозиты, Цели (списки)
| | Desktop | Tablet | Mobile |
|---|---|---|---|
| Сетка карточек | 3 колонки (счета, цели, депозиты); категории — таблица 2 вкладок | 2 колонки | 1 колонка |
| Группировка | По валюте (счета) | То же | То же, заголовки-разделители |

### Бюджеты (B-1, B-2)
Desktop — 2 колонки карточек с прогрессом. Tablet — 1 колонка широких карточек. Mobile — компактный список: название, «X из Y ₸», прогресс-бар, бейдж статуса. В деталях выбор месяца — select на mobile и стрелки «‹ ноябрь 2026 ›» на desktop.

### Аналитика (AN-1, AN-2)
| | Desktop | Tablet | Mobile |
|---|---|---|---|
| Фильтры | Пресеты периода (segmented) + DateRangePicker + валюта | Select периода + валюта | Кнопка «Ноябрь 2026 · KZT» → лист фильтров |
| Сводка | 6 метрик в 2 ряда | 3×2 | Список метрик |
| Графики | 2 колонки | 1 колонка | 1 колонка, высота 220, подписи осей сокращены; tooltip по тапу |
| Таблица категорий | Полная: категория, сумма, доля, операций | Без «операций» | Список: категория + сумма, доля — прогресс-полосой |

### Депозиты — калькулятор (DP-3)
Desktop: форма слева (5/12), результат справа (7/12), закреплённый при скролле. Tablet: форма сверху, результат снизу. Mobile: форма → кнопка «Рассчитать» → результат ниже, с автоскроллом к нему.

### AI-советник (AI-1, AI-2)
Desktop: чат по центру (макс. 760 px), справа панель «Факты и допущения» последнего ответа. Tablet: панель фактов — раскрывающийся блок под ответом. Mobile: поле ввода закреплено над клавиатурой; факты — раскрывающиеся под каждым ответом; отчёт AI-2 — аккордеон секций (Сводка, Наблюдения, Рекомендации, Риски).

### Настройки (S-1…S-3)
Desktop — вертикальные вкладки слева (Общие, Оформление, Безопасность). Tablet — горизонтальные вкладки. Mobile — список разделов, каждый открывается отдельным экраном.

### Аутентификация (A-1…A-4)
Desktop и Tablet — карточка 400 px по центру на фоне `background`; на desktop слева допускается панель 40 % с названием продукта и тремя тезисами (без иллюстраций, закрывающих форму). Mobile — форма на всю ширину, поля 48 px, кнопка на всю ширину.

## 3. Обязательный набор кадров в Figma

| Экран | Desktop L/D | Tablet L/D | Mobile L/D |
|---|---|---|---|
| Вход | ✔ | — | ✔ |
| Обзор | ✔ | ✔ | ✔ |
| Транзакции: список | ✔ | ✔ | ✔ |
| Транзакция: форма | ✔ | — | ✔ |
| Бюджеты: список | ✔ | — | ✔ |
| Аналитика: обзор | ✔ | ✔ | ✔ |
| AI-советник: чат | ✔ | — | ✔ |
| Остальные экраны | ✔ | — | по запросу |

L/D — светлая и тёмная тема. Итого: 33 экрана × 2 темы на desktop (66 кадров) + 10 адаптивных кадров (3 tablet + 7 mobile) × 2 темы (20 кадров) = **86 кадров** без учёта состояний (loading, empty, error, validation).

## 4. Правила для таблиц на узких экранах
1. Колонки скрываются по приоритету, сумма и описание — никогда.
2. Сумма всегда видна целиком: перенос описания, но не суммы.
3. Ни одна таблица на mobile не требует горизонтального скролла: переход на карточки.
4. Действия строки на mobile — по тапу на карточку (детали) и в меню «⋯», без hover.
